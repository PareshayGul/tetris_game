Tetris is a classic puzzle video game where player arranges falling blocks to make
solid horizontal lines.  It improves your spatial awareness, sharpens players reflexes.
Player can move blocks in width as they fall and there their position too to adjust
them together to make a solid line as the number of disappearing line increases the
time of the block hitting the floor increases. If the blocks stack over each other 
and reach top game is over.
Language  C++17
Graphics and framework :SFML(SFML Graphics, SFML Window, SFML System)
Compiler: Microsoft Visual C++ (MSVC)
Build tool: Visual Studio / MSBuild
Platform: Windows
Rendering 2D sprite-based rendering
Game loop: Event-driven loop with a 60 FPS frame limit
The project is pink pastel colour themed
Once running click the play button if player knows how to play if not go to settings 
to exit setting click back to menu. One game is started blocks will start falling from 
to bottom player can adjust the blocks horizontally by moving left and right and avoid 
hitting the top once it hits the top game is over. Score Level of difficulty and lines 
disappeared are showed and player and click on yes to play again or go back to home.
